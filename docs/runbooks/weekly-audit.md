# Weekly audit runbook

Run the audit in an isolated worktree.

Check production availability, broken links, dependency/security alerts, content freshness, résumé consistency, accessibility, SEO, performance, metadata, and production smoke paths. Open an issue for every material finding.

The first two runs are report-only. After the owner reviews their precision, the workflow may prepare draft pull requests only for low-risk dependency, test, documentation, or presentation fixes. It must never merge or deploy. Post only the sanitized report or draft-PR link to the dedicated Slack channel.
