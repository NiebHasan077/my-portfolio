# Security policy

Do not open a public issue for suspected credential exposure, cross-site scripting, dependency compromise, or private-data leakage. Contact the repository owner privately through the verified address configured in the GitHub Security tab.

The published portfolio is static. It has no contact form, visitor storage, cookies, or third-party analytics. Security controls include a restrictive content security policy, secure response headers, HTTPS-only external links, dependency review, secret scanning, and a claim-gated public résumé.

Private source documents, residential addresses, phone numbers, credentials, webhook URLs, account identifiers, and unapproved professional claims must never enter the public repository or generated site.
